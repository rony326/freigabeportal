# RFC3161-Zeitstempel für abgeschlossene Rechnungen Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Embed a PAdES-style RFC3161 trusted timestamp into every invoice PDF at Freigabe-2 completion (proving the finalized document is unchanged since time T, for GeBüV-compliant archival), with a configurable TSA endpoint, non-blocking best-effort behavior plus automatic/manual retry, two in-portal verification entry points, a hard gate that keeps n8n from picking up (and thereby permanently losing the ability to timestamp) a job before it has one, and an admin-visible warning when that gate leaves jobs stuck.

**Architecture:** A new, small service module (`src/services/zeitstempel.js`) wraps the `pdf-rfc3161` library behind two functions — `setZeitstempel` (embed, throws on failure like the existing `stampAndFinalize`) and `verifyZeitstempel` (inspect, never throws). `freigabe2.js` calls `setZeitstempel` right after its existing `stampAndFinalize` call, best-effort or not at all: nothing about that route's success path may block on TSA availability. A new `jobs.zeitstempel_gesetzt_am` column records success; failures are simply retried later by a new cron job (`runZeitstempelNachholenJob`) that follows the exact existing pattern in `src/services/cronJobs.js` (manual trigger under `/admin/geplante-jobs`, scheduled trigger in `scheduler.js`, on-demand trigger under `/internal/cron`). Verification gets its own small standalone route (`/zeitstempel-pruefen`, upload-a-PDF or `?jobId=`) plus a new "Meine abgeschlossenen Rechnungen" Dashboard section linking into it. TSA configuration (URL, optional Basic-Auth username/password, admin-warning threshold) lives in `admin_config`, editable via a new `/admin/zeitstempel` page — a deliberate, spec-approved exception to this project's usual secrets-in-.env-only convention. Because n8n deletes a job's PDF file the moment it confirms pickup (making a timestamp permanently unsettable afterward), `src/routes/n8n/jobs.js`'s two pickup endpoints gain a gate — driven by the existing `zeitstempel_gesetzt_am` column and a new `jobs.abgeschlossen_am` column — that hides/refuses a job until it has a timestamp, whenever the feature is active; a new admin-dashboard banner (`countZeitstempelUeberfaellig`) surfaces the resulting operational risk if a TSA stays unreachable for too long.

**Tech Stack:** Node.js, Express, `node:sqlite`, EJS views, `pdf-rfc3161` (new dependency — pure JS, no native deps, Node's built-in `fetch`), `node:test` + `supertest` + `undici`'s `MockAgent` for tests (`npm test` runs `node --test 'test/**/*.test.js'`).

**Spec:** docs/superpowers/specs/2026-08-17-rfc3161-zeitstempel-design.md

## Global Constraints

- No migration system exists for CHECK-constraint changes — `schema.sql` is edited directly, and any table whose CHECK is widened needs the SQLite rename-recreate-copy-drop pattern already used in `migrateFreigabenTable` (`src/db/index.js`) for already-existing on-disk databases (not needed in this plan: no CHECK constraints change, only a new nullable column via `ALTER TABLE ADD COLUMN`, which the existing `JOBS_TABLE_MIGRATIONS` array pattern already covers).
- `node:sqlite`'s FK constraints are actively enforced — every `createKonto`/`createJob`/`createFreigabe` call in tests needs its referenced `personen` rows to already exist via `upsertPerson`.
- EJS views: `<%- %>` only for trusted includes, `<%= %>` for all real data.
- German-language strings throughout (route messages, labels, email subjects/bodies) — match the existing tone exactly when copying patterns.
- **Deviation from the spec's pseudocode, confirmed by inspecting the real `pdf-rfc3161@0.1.4` published API (`node_modules/pdf-rfc3161/dist/index.d.ts`):** there is no `tsa.auth` option. TSA Basic-Auth (optional username/password) must be built manually into a `headers: { Authorization: 'Basic <base64>' }` entry — see Task 1.
- **`timestampPdf` must always be called with `omitModificationTime: true`.** Without it, the library embeds the current wall-clock time into the PDF's signed byte range on every call, making the hash — and therefore this plan's whole test-fixture strategy — non-reproducible. Confirmed empirically while writing this plan (see Task 1's fixture rationale). This is also the more correct choice: the embedded RFC3161 token already carries the authoritative time, per the library's own doc comment.
- **No live network calls in any test**, matching this project's existing convention (`test/helpers/mockChurchTools.js` mocks ChurchTools via `undici`'s `MockAgent`+`setGlobalDispatcher`, which intercepts Node's built-in `fetch` — `pdf-rfc3161`'s `sendTimestampRequest` also uses plain `fetch`, so the identical mechanism applies). Two binary fixtures captured once from the real FreeTSA server during planning (Task 1) make this possible without any mocked TSA needing to fabricate cryptographically-valid ASN.1 by hand.
- `zeitstempel_tsa_url` empty/unset = feature disabled everywhere (Freigabe-2 completion and the nachhol-job both skip silently, no log entry, no error) — this also covers Task 9's n8n pickup gate and Task 10's admin warning: both compute their own `Boolean(getConfigValue(db, 'zeitstempel_tsa_url'))` and are fully inert when it's empty, so the feature stays invisible on any installation before its first TSA setup.

### Task 1: `zeitstempel.js` service (embed + verify RFC3161 timestamps)

**Files:**
- Modify: `package.json` (new dependency)
- Create: `src/services/zeitstempel.js`
- Create: `test/helpers/mockTsa.js`
- Create: `test/fixtures/rfc3161-response.der` (binary, captured once from the real FreeTSA server — see rationale below)
- Create: `test/fixtures/rfc3161-timestamped.pdf` (binary, same origin)
- Test: `test/unit/zeitstempel.test.js`

**Interfaces:**
- Produces: `setZeitstempel(pdfBuffer, tsaConfig)` → `Promise<Buffer>`. `tsaConfig = { url, user, passwort }` (`user`/`passwort` optional). Throws `Error` with a German message (`Zeitstempel konnte nicht gesetzt werden: ...`) on any failure — network, TSA rejection, malformed PDF.
- Produces: `verifyZeitstempel(pdfBuffer)` → `Promise<{ vorhanden: boolean, gueltig: boolean, zeitpunkt: string|null, tsaPolicy: string|null }>`. Never throws — a missing/corrupt/invalid timestamp is a normal, displayable result, not an error. `zeitpunkt` is an ISO-8601 UTC string (from the TSA's `genTime`) when `vorhanden` is `true`, otherwise `null`. `tsaPolicy` is the TSA's policy OID string when `vorhanden` is `true`, otherwise `null`.
- Produces: `setupMockTsa(url)` (test helper) → returns an `undici` `MockPool` for `url`'s origin, exactly mirroring `test/helpers/mockChurchTools.js`'s `setupMockChurchTools`. Callers chain their own `.intercept({ path, method }).reply(...)`.
- Consumes: nothing from earlier tasks (this task has no dependencies — it's pure PDF/TSA logic, no DB).

**Why this task looks the way it does (read before implementing):**

The design spec's pseudocode (`tsa: { url, auth }`) does not match the real, published `pdf-rfc3161@0.1.4` API. Its `TSAConfig` type has **no `auth` field at all** — only `url`, `hashAlgorithm`, `policy`, `requestCertificate`, `headers`, `timeout`, `retry`, `retryDelay`. Optional TSA Basic-Auth must be built by hand into a `headers: { Authorization: 'Basic <base64>' }` entry. This was confirmed by installing the real package and inspecting `node_modules/pdf-rfc3161/dist/index.d.ts` — do the same if anything here seems to disagree with what you see installed.

`timestampPdf({ pdf, tsa, omitModificationTime: true })` must always pass `omitModificationTime: true`. Without it, the library embeds the current wall-clock time into the PDF's signed byte range on every call, which (a) is redundant — the embedded RFC3161 token already carries the authoritative time — and (b) makes the byte range's hash different on every single call, which breaks this task's whole test strategy (below).

**Fixture strategy (why two binary fixtures, captured for real, are checked in):**

`pdf-rfc3161` has no way to inject a fake/mock TSA response generator — `timestampPdf` calls Node's global `fetch` directly (confirmed by reading `node_modules/pdf-rfc3161/dist/index.js`: `POST <tsa.url>` with `Content-Type: application/timestamp-query`, body = DER-encoded request, expecting a `Content-Type: application/timestamp-reply` DER response). That's the exact same mechanism `src/services/churchtools.js` and `test/helpers/mockChurchTools.js` already use and mock via `undici`'s `MockAgent` + `setGlobalDispatcher` (which intercepts Node's built-in `fetch`) — so `test/helpers/mockTsa.js` mirrors `mockChurchTools.js` exactly.

Fabricating a cryptographically valid RFC3161 response by hand (real ASN.1/CMS/X.509 structures) is impractical and error-prone to hand-write. Instead, two real responses were captured once from the actual FreeTSA server (`https://freetsa.org/tsr`) while writing this plan, and are checked in as static binary fixtures — no test ever makes a live network call.

- `test/fixtures/rfc3161-response.der`: one real, raw TSA response (DER-encoded `TimeStampResp`). Used only to mock the TSA HTTP endpoint for `setZeitstempel`'s **embedding** tests — it proves the code calls the TSA correctly and successfully embeds *a* timestamp structure. It is **not** asserted to be cryptographically valid against the fresh PDF bytes generated at test time, because (confirmed empirically) `pdf-lib`'s `.save()` embeds a creation-time-dependent value that shifts the output by a few bytes between process runs at different real-world moments, so a byte-for-byte-reproducible request hash across arbitrary future test runs cannot be guaranteed. `setZeitstempel`'s embedding tests therefore only assert the call succeeds and a timestamp structure is present (`vorhanden: true`), never `gueltig: true`, for this fixture.
- `test/fixtures/rfc3161-timestamped.pdf`: one complete, real, **self-consistent** output of a real `timestampPdf()` call (original PDF + its own genuinely matching embedded token, produced together in the same call). Because it's a single static file that's never regenerated, it verifies as fully valid (`gueltig: true`) forever, deterministically, with zero network dependency. Used for `verifyZeitstempel`'s "valid timestamp present" test.

Both fixtures were captured against a PDF built via the existing `test/helpers/pdfFixture.js`'s `buildPdfFixture(['RFC3161 Testfixtur, feste Bytes für reproduzierbaren Zeitstempel-Test.'])`. The captured `genTime` is `2026-08-21T07:21:19.000Z` and `policy` is `1.2.3.4.1` for `rfc3161-timestamped.pdf` — these exact values are asserted in the tests below; if you ever need to recapture the fixtures (e.g. testing against a different TSA), update those two assertions to match.

Create `test/helpers/mockTsa.js`:

```javascript
import { MockAgent, setGlobalDispatcher } from 'undici';

// Mirrors mockChurchTools.js's mechanism: undici's MockAgent intercepts Node's global fetch
// (which pdf-rfc3161's sendTimestampRequest uses directly, exactly like churchtools.js does for
// ChurchTools), so tests never make a real network call to a TSA. Returns the MockPool for url's
// origin so callers chain their own `.intercept({ path, method }).reply(...)` per expected
// request, exactly like setupMockChurchTools.
export function setupMockTsa(url) {
  const mockAgent = new MockAgent();
  mockAgent.disableNetConnect();
  setGlobalDispatcher(mockAgent);
  return mockAgent.get(new URL(url).origin);
}
```

```javascript
import { timestampPdf, extractTimestamps, verifyTimestamp } from 'pdf-rfc3161';

// Bounded well below the library's own defaults (timeout 30000ms, retry 3, retryDelay 1000ms —
// worst case over 90s) because setZeitstempel runs synchronously inside the Freigabe-2 POST
// request (see freigabe2.js): a hung/unreachable TSA must fail fast so the request can fall
// through to its non-blocking "best-effort, retried later by the nachhol-job" behavior instead of
// leaving the submitting person's browser hanging for a minute and a half.
const TSA_TIMING = { timeout: 8000, retry: 1, retryDelay: 300 };

// pdf-rfc3161's TSAConfig has no built-in `auth` option (confirmed against the real published
// API — see this task's notes above), so TSA Basic-Auth has to be built by hand into a header.
// Only needed for a production-grade TSA that requires credentials; FreeTSA does not.
function buildTsaHeaders(tsaConfig) {
  if (!tsaConfig.user) return undefined;
  const credentials = Buffer.from(`${tsaConfig.user}:${tsaConfig.passwort || ''}`).toString('base64');
  return { Authorization: `Basic ${credentials}` };
}

// Embeds a PAdES-style RFC3161 DocTimeStamp into the PDF, proving the document existed unchanged
// since the TSA's timestamp. Throws a German-message Error on any failure (network, TSA
// rejection, malformed PDF) — mirrors src/services/pdfStamp.js's stampAndFinalize, whose callers
// already expect a catchable, user-facing German message rather than the library's raw error.
// omitModificationTime is required, not optional — see this task's notes above.
export async function setZeitstempel(pdfBuffer, tsaConfig) {
  try {
    const result = await timestampPdf({
      pdf: pdfBuffer,
      tsa: { url: tsaConfig.url, headers: buildTsaHeaders(tsaConfig), ...TSA_TIMING },
      omitModificationTime: true,
    });
    return Buffer.from(result.pdf);
  } catch (err) {
    throw new Error(`Zeitstempel konnte nicht gesetzt werden: ${err.message}`);
  }
}

// Never throws: a PDF with no timestamp, a corrupt/unreadable PDF, or a cryptographically invalid
// timestamp are all normal, displayable outcomes for the verification UI (dashboard link, upload
// tool) — not error conditions the caller needs to catch.
export async function verifyZeitstempel(pdfBuffer) {
  const LEER = { vorhanden: false, gueltig: false, zeitpunkt: null, tsaPolicy: null };
  let extrahiert;
  try {
    extrahiert = await extractTimestamps(pdfBuffer);
  } catch {
    return LEER;
  }
  if (extrahiert.length === 0) {
    return LEER;
  }
  const verifiziert = await verifyTimestamp(extrahiert[0], { pdf: pdfBuffer });
  return {
    vorhanden: true,
    gueltig: verifiziert.verified,
    zeitpunkt: verifiziert.info.genTime.toISOString(),
    tsaPolicy: verifiziert.info.policy,
  };
}
```

```javascript
// Same rationale as migrateFreigabenTable above: an already-existing cron_log table (any database
// that predates the 'zeitstempel-nachholen' job name) keeps its original, narrower CHECK forever
// otherwise, and logCronLauf('zeitstempel-nachholen', ...) would fail on it.
function migrateCronLogTable(db) {
  const tableSql = db.prepare("SELECT sql FROM sqlite_master WHERE type = 'table' AND name = 'cron_log'").get();
  if (!tableSql || tableSql.sql.includes('zeitstempel-nachholen')) return;

  db.exec('BEGIN');
  try {
    db.exec('ALTER TABLE cron_log RENAME TO cron_log_pre_zeitstempel_nachholen');
    db.exec(`
      CREATE TABLE cron_log (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        job TEXT NOT NULL CHECK(job IN ('pool-erinnerungen', 'pdf-bereinigung', 'zeitstempel-nachholen')),
        gestartet_am TEXT NOT NULL,
        beendet_am TEXT NOT NULL,
        status TEXT NOT NULL CHECK(status IN ('erfolg', 'fehler')),
        details TEXT
      )
    `);
    db.exec(`
      INSERT INTO cron_log (id, job, gestartet_am, beendet_am, status, details)
      SELECT id, job, gestartet_am, beendet_am, status, details FROM cron_log_pre_zeitstempel_nachholen
    `);
    db.exec('DROP TABLE cron_log_pre_zeitstempel_nachholen');
    db.exec('COMMIT');
  } catch (err) {
    db.exec('ROLLBACK');
    throw err;
  }
}
```

```javascript
// Best-effort retry for jobs whose Freigabe-2 completion (freigabe2.js) either had no TSA
// configured at the time, or attempted setZeitstempel and failed (TSA outage). Silently does
// nothing (no log entry) when the feature is unconfigured, matching setZeitstempel's own
// "empty zeitstempel_tsa_url = feature disabled" behavior at Freigabe-2 completion. Each pending
// job is tried independently — one job's TSA failure or missing PDF file must never stop the
// others in the same run from being retried.
export async function runZeitstempelNachholenJob(db, config) {
  const gestartetAm = new Date().toISOString();
  const tsaUrl = getConfigValue(db, 'zeitstempel_tsa_url');
  if (!tsaUrl) {
    return { status: 'uebersprungen', nachgeholt: 0 };
  }
  try {
    const tsaConfig = {
      url: tsaUrl,
      user: getConfigValue(db, 'zeitstempel_tsa_user') || undefined,
      passwort: getConfigValue(db, 'zeitstempel_tsa_passwort') || undefined,
    };

    const ausstehend = db.prepare("SELECT * FROM jobs WHERE status = 'abgeschlossen' AND zeitstempel_gesetzt_am IS NULL").all();
    let nachgeholt = 0;
    let fehlgeschlagen = 0;
    let dateiFehlt = 0;
    for (const job of ausstehend) {
      // Bekannte Einschränkung (siehe Spec): sobald n8n den Job abgeholt hat, löscht das Portal
      // die lokale PDF-Datei -- ein Zeitstempel kann für diesen Job dann nicht mehr nachgeholt
      // werden. Kein Fehler, nur ein Zählwert für die Sichtbarkeit im Log.
      if (!job.pdf_pfad || !existsSync(job.pdf_pfad)) {
        dateiFehlt += 1;
        continue;
      }
      try {
        const pdfBuffer = readFileSync(job.pdf_pfad);
        const stamped = await setZeitstempel(pdfBuffer, tsaConfig);
        const tmpPfad = `${job.pdf_pfad}.${randomUUID()}.tmp`;
        writeFileSync(tmpPfad, stamped);
        renameSync(tmpPfad, job.pdf_pfad);
        markZeitstempelGesetzt(db, job.id, new Date().toISOString());
        nachgeholt += 1;
      } catch (err) {
        fehlgeschlagen += 1;
        console.error(`Zeitstempel-Nachholen für Job ${job.id} fehlgeschlagen:`, err.message);
      }
    }

    const ergebnis = { status: 'erfolg', nachgeholt, fehlgeschlagen, dateiFehlt };
    logCronLauf(db, {
      job: 'zeitstempel-nachholen',
      gestartetAm,
      beendetAm: new Date().toISOString(),
      status: 'erfolg',
      details: `Nachgeholt: ${nachgeholt}, Fehlgeschlagen: ${fehlgeschlagen}, Datei fehlt: ${dateiFehlt}`,
    });
    return ergebnis;
  } catch (err) {
    logCronLauf(db, { job: 'zeitstempel-nachholen', gestartetAm, beendetAm: new Date().toISOString(), status: 'fehler', details: err.message });
    return { status: 'fehler', error: err.message };

}
```

```javascript
import { Router } from 'express';
import multer from 'multer';
import { readFileSync, existsSync } from 'node:fs';
import { getJobById } from '../db/jobsRepo.js';
import { canViewJobPdf } from '../services/jobAuthorization.js';
import { verifyZeitstempel } from '../services/zeitstempel.js';

const upload = multer({ storage: multer.memoryStorage(), limits: { fileSize: 25 * 1024 * 1024 } });

export function createZeitstempelPruefenRouter({ db, config }) {
  const router = Router();

  router.get('/', async (req, res, next) => {
    try {
      const jobId = req.query.jobId ? Number(req.query.jobId) : null;
      if (!jobId) {
        return res.render('zeitstempel-pruefen', { ergebnis: null, errors: [], jobId: null, job: null });
      }
      const job = getJobById(db, jobId);
      if (!job || !canViewJobPdf(db, config, req.currentPerson, job)) {
        return res.status(403).render('error', { message: 'Kein Zugriff auf diesen Job.' });
      }
      if (!job.pdf_pfad || !existsSync(job.pdf_pfad)) {
        return res.status(404).render('error', { message: 'PDF-Datei für diesen Job ist nicht mehr vorhanden.' });
      }
      const ergebnis = await verifyZeitstempel(readFileSync(job.pdf_pfad));
      res.render('zeitstempel-pruefen', { ergebnis, errors: [], jobId, job });
    } catch (err) {
      next(err);
    }
  });

  router.post('/', (req, res, next) => {
    upload.single('pdf')(req, res, async (uploadErr) => {
      try {
        if (uploadErr) {
          const message = uploadErr.code === 'LIMIT_FILE_SIZE' ? 'Die Datei darf höchstens 25 MB gross sein.' : 'Fehler beim Datei-Upload.';
          return res.status(400).render('zeitstempel-pruefen', { ergebnis: null, errors: [message], jobId: null, job: null });
        }
        if (!req.file) {
          return res.status(400).render('zeitstempel-pruefen', { ergebnis: null, errors: ['Bitte eine PDF-Datei auswählen.'], jobId: null, job: null });
        }
        const ergebnis = await verifyZeitstempel(req.file.buffer);
        res.render('zeitstempel-pruefen', { ergebnis, errors: [], jobId: null, job: null });
      } catch (err) {
        next(err);
      }
    });
  });

  return router;
}
```

Add to `src/db/jobsRepo.js`, right after `listFreigabe2JobsForPerson`:

```javascript
// Same konto-membership logic as listFreigabe2JobsForPerson, widened to the three
// completed-and-beyond statuses (so it keeps listing a job after n8n abholt/archiviert it, even
// though its PDF file is no longer available to preview/verify by then) plus a direct
// zugewiesen_an match (the person who did the Kontierung, not necessarily the Freigeber2).
export function listAbgeschlossenJobsForPerson(db, personId) {
  return db
    .prepare(
      `SELECT jobs.* FROM jobs
       JOIN konten ON konten.id = jobs.konto_id
       WHERE jobs.status IN ('abgeschlossen', 'abgeholt', 'archiviert')
         AND (
           jobs.zugewiesen_an = ?
           OR (jobs.freigabe2_eskaliert_von IS NULL AND konten.freigeber2_id = ?)
           OR (jobs.freigabe2_eskaliert_von IS NOT NULL AND konten.stellvertreter2_id = ?)
         )
       ORDER BY jobs.eingang_am DESC`
    )
    .all(personId, personId, personId);
}
```

```javascript
import { Router } from 'express';
import { getConfigValue, setConfigValue } from '../../db/adminConfigRepo.js';

const URL_PATTERN = /^https?:\/\//;

export function createZeitstempelAdminRouter({ db }) {
  const router = Router();

  function currentState() {
    return {
      tsaUrl: getConfigValue(db, 'zeitstempel_tsa_url') ?? '',
      tsaUser: getConfigValue(db, 'zeitstempel_tsa_user') ?? '',
    };
  }

  router.get('/', (req, res) => {
    res.render('admin/zeitstempel-form', { ...currentState(), errors: [], gespeichert: req.query.gespeichert === '1' });
  });

  router.post('/', (req, res) => {
    const { tsaUrl, tsaUser, tsaPasswort } = req.body;
    const trimmedUrl = (tsaUrl || '').trim();
    const trimmedUser = (tsaUser || '').trim();
    const errors = [];
    if (trimmedUrl && !URL_PATTERN.test(trimmedUrl)) {
      errors.push('TSA-URL muss leer sein (Funktion deaktiviert) oder mit http:// oder https:// beginnen.');
    }

    if (errors.length > 0) {
      return res.status(400).render('admin/zeitstempel-form', {
        tsaUrl: trimmedUrl,
        tsaUser: trimmedUser,
        errors,
        gespeichert: false,
      });
    }

    setConfigValue(db, 'zeitstempel_tsa_url', trimmedUrl);
    setConfigValue(db, 'zeitstempel_tsa_user', trimmedUser);
    setConfigValue(db, 'zeitstempel_tsa_passwort', tsaPasswort || '');
    res.redirect('/admin/zeitstempel?gespeichert=1');
  });

  return router;
}
```
